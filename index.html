How do grids work in css?

Its mainly grid-template-rows and grid-template-columns for settings how the cels are arranged on the page. Then you must use grid-row and grid-column to set which elements are going in which cells. And use grid-template-areas if you want to name elements and fill those areas. grid-area takes in 4 values, row-start, column-start, row-end, column-end. To make an element use its next cel too use span but then will get overwritten by manuallu setting the locations. You can also use -1 in grid-template-columns or grid-template-rows to get to the end of the cells.
